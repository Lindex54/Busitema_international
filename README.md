# Busitema University Internationalization & Partnerships

Starter project structure for the frontend-first PHP website.

## Main areas
- Public website pages
- Reusable includes
- Reusable frontend components
- App layer placeholders
- Admin panel placeholders
- Upload directories
- Database scripts

6. Opportunities

8. Life in Uganda
9. News and Events
